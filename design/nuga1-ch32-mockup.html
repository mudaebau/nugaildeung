장면 1 — 대회홈: 여정 = 줄마다 자기 버튼 (대칭 구조)

개설↔[정보 수정](항상 활성) / 모집↔[마감/재개] / 예선↔[예선 마감] / 결승↔[결승 시작] / 종료↔[종료 확정]. 지금 할 것만 파랑, 아직인 것은 회색(비활성), 지난 것은 옅은 파랑(보조) — 순서와 상태가 버튼 색으로 읽힙니다. 예선 마감↔결승 시작 분리(사이에 명단·조편성 시간). 단계 시작 버튼 = 사전 점검 시트 선행(명단 확정·조편성·심판 상태 확인 후 시작) · 회색 버튼 탭 = 이유 토스트. 단계 수 따라 줄 자동 증감.
