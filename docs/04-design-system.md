## 2. 타이포
- 본문·제목: **Noto Sans KR** — 굵기 400/500/700, **800 이상 금지** (로고 워드마크도 700)
- 숫자(점수·순위·통계): **Oswald** 600/700 + tabular
- Black Han Sans 등 장식 폰트 금지 (폐기됨)
- 최소 크기: 본문 13px, 보조 11px 아래 금지. 시니어 화면(전광판·심판)은 한 단계 더 크게

## 3. 형태·컴포넌트
- 라디우스: 카드 16~20 / 히어로·포스터 24~30 / 칩·뱃지 99(pill) / 입력 12~14
- 카드: 흰 배경 + --line 1px 테두리 (그림자 최소, 포스터 겹침 카드만 soft shadow)
- 터치 타깃: 최소 44×44, 주요 버튼 높이 46~54
- 칩(.chiprow): 가로 스크롤 시 **touch-action:pan-x 필수**
- 시트(바텀시트): 확인·경고·기록내역 등 모든 2차 결정. dim + 하단 라운드 시트, 주 버튼 1 + 취소
- 여정 바 / 완성도 %바 / 진행 뱃지: 기존 컴포넌트 재사용, 신규 변형 금지
- 목록 행 높이 46~56, 아바타(이니셜 원형) 40

## 4. 브랜드 (v3 — 말풍선 로고)
- 컨셉: "누가 1등이야?" — 말풍선 속 골드 숫자 1. 컬러 C(딥네이비×화이트×골드) 확정
- 자산: logo-main(밝은 지면) / logo-light(어두운 지면·인쇄·**앱바 28~52px**) / app-icon·favicon(1-풍선) / logo-appbar(무풍선, 미사용 보존)
- 규칙: 풍선+꼬리 단일 패스 분리 금지 · 숫자 1은 항상 골드 · 워드마크 40px 미만 축소 금지(아이콘으로 대체)

## 5. 화면 문법
- 위저드: 한 화면 한 질문, 상단 진행바, 하단 고정 [다음]
- 관리 화면: 앱바(대회명+상태 부제, URL 노출 금지) + 서브탭(아이콘 언더라인 7개 균등)
- 상태 기억 규칙: **단계를 기억하는 UI 상태는 화면 진입 시 활성 단계로 리셋**
- 빈 상태: 안내 문구 + 행동 버튼 (조편성 빈 화면 등)
- 미입력 정보: 참가자 화면에서는 행·카드째 숨김 (빈 줄 노출 금지)
