# 누가일등 — 제품 기획서 (v2.5 기준 통합본)

## 1. 한 줄 정의
파크골프 대회의 개설부터 시상까지 폰 하나로 끝내는 **대회 관리 플랫폼**. 웹 기반(설치 없음), 시니어 우선 설계.

## 2. 문제
- 클럽 월례회·매장 대회의 운영은 총무 한 사람의 수기(엑셀·종이 스코어카드·단톡방)에 의존
- 순위 집계가 느리고 실수가 잦아 시상 분쟁 발생, 대회의 열기가 "결과 기다림"에서 식음
- 스크린파크골프 매장은 기간형 대회(코스 도전·베스트 갱신)를 돌릴 도구 자체가 없음

## 3. 사용자 (3역할)
| 역할 | 대표 인물상 | 핵심 과업 |
|---|---|---|
| 운영자 | 클럽 총무(60대), 매장 점주 | 개설→모집→조편성→진행→시상 |
| 참가자 | 시니어 회원 (폰 미숙 전제) | 요강 확인→신청→내 순위 확인 |
| 심판 | 조별 기록 담당 (가입 없음) | 문자 링크→홀 점수 입력 |

## 4. 핵심 가치
1. **실시간 전광판** — 대회의 열기를 만드는 중심 화면 (TV·폰 겸용)
2. **접수 자동화** — 링크 하나로 신청·명단·조편성
3. **공정한 기록** — 정정 로그, 컷 동점 규칙, 서버 검증 (신뢰가 상품)
4. **시니어 친화** — 큰 글자·큰 터치·한 화면 한 질문

## 5. 대회 매트릭스 (수용 범위 = 영업 범위)
**필드/스크린 × 1~3단계 × 단계별 [지정일 라운드|기간 도전] × [조편성 유무] × [홀별|총점만] × [공개|비공개] × [정원|무제한] × 참여조건**
- 기간형 = 기간 중 무제한 도전, 코스별 베스트 합산 (스크린 예선의 표준)
- 컷 = 남N/여N 분할 지원, 동점 규칙(카운트백/연장/연장자/별도선정)

## 6. 비즈니스 맥락
- 운영사: 임팩트파크골프/다원솔루텍 — 스크린파크골프 장비·프랜차이즈와 연계
- 1차 고객: 자사 가맹점 대회 + 지역 클럽. B2G(지자체 생활체육) 확장 여지
- 계정: **전화번호 = 계정** (예외 없음). 간이 인증은 파일럿까지, 정식 오픈 전 문자 OTP(솔라피)

## 7. 로드맵 — 제품 버전과 개발 차수 분리
개발 차수(CH1~27...)는 작업 단위, 제품 버전은 사업 마일스톤. 혼용 금지.
- **v0.8 Pilot (현재 목표)**: CH25~28 완료 → 전수 검증 → 20~40명 필드 단판 파일럿
- **v0.9 Beta**: 파일럿 피드백 반영 + 구조 보강(ES Module 분리·CLI 마이그레이션·OTP·조직 권한) + 2~3개 매장 베타 + PC/와이드 대응
- **v1.0 Launch**: 정식 오픈 (유료화 여부 판단 포함)
- **v2.x**: 스코어카드 사진 입력(AI 판독) 재도입, 임팩트비전 시스템 직접 연동, 대회 복제·CSV 내보내기 고도화
