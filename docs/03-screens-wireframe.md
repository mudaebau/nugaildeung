# 누가일등 — 화면 정의서 (텍스트 와이어프레임)

> 시각 기준은 design/ 폴더 목업 HTML이 원본. 이 문서는 화면 목록·구성·상태·이동의 사전.
> 표기: [버튼] (요소) {상태} → 이동

## A. 공개 화면 (로그인 불요)

### A1. 홈
(앱바: logo-light 흰 풍선 + 로그인 상태) / (히어로: 배지로고·태그라인·[+ 새 대회 개설]) / (필터 칩: 전체·진행중·접수중·지난대회) / (대회 카드 피드: LIVE=네이비 카드+전광판 링크, 접수중=D-day+모집 현황) / (푸터: 개인정보 처리방침) — 하단 3탭

### A2. 요강 (카드뉴스) — ?t={id}
(포스터 히어로{접수중 D-N|진행 중|종료}) / (핵심 4카드) / (상금 카드{미입력=숨김}) / (시상 내역) / (진행 방식 도해) / (자격·문의) — 하단 고정 [참가 신청하기]{마감=접수 마감|종료=결과 보기} + [↗ 링크·이미지]
- 비공개: 비밀번호 게이트 → 통과 시 세션 유지

### A3. 참가 신청 — /apply
(세그먼트: 개인|단체) / 개인: (이름)(전화)(성별·나이·소속{대회 설정 항목만})(조건 확인 체크{조건 대회})(개인정보 동의 체크★필수) [신청하기] / 단체: (클럽명)(명단 붙여넣기→인식 미리보기{전화 마스킹}) [일괄 신청]
→ 완료 화면(옐로우 히어로·접수 번호·전광판 안내) / {정원 마감}=대기 신청 안내{무제한=없음} / {접수 마감}=마감 안내

### A4. 전광판 — /board
(헤더: ←·대회명·아이콘[전체화면][자동순환][⋯{경기종료·초기화}]) / (필터: 부문 3칩 + 범위 칩{2코스+}) / (메타 한 줄) / (순위 행: 순위|선수|코스소계|스코어|진행|합계, 1위 골드) {연결 끊김=재접속 배지}
- TV 모드: 대형 타이포, 자동 순환(부문)

### A5. ?privacy / ?guide
처리방침 정적 페이지 / 운영자 1장 가이드(개설→모집→당일→시상)

## B. 운영자 화면

### B1. 내 대회
(대회 카드: 상태 뱃지+핵심 숫자+할 일 뱃지{차수27}) → 관리공간. {1개면 직행}

### B2. 개설 위저드 (5~7화면)
P1 프리셋 → P2 대회명·주최 → P3 단계 설정{단계 수만큼} → P4 일정+정원 → P5 완료([링크 복사]·나중에 입력 목록)
- 공통: 진행바, 뒤로가기, 한 화면 한 질문

### B3. 관리홈
(앱바: 대회명+단계 부제) / (여정 바: 접수{접수중|마감 뱃지}→단계들→종료) / (접수 카드: 신청·대기·입금 집계+[접수 마감/재개]) / (현 단계 현황: 기간형=D-day·완주·컷 경쟁 / 라운드형=조 진행·심판 접속) / (도구: 전광판·신청 링크 공유) / ([대회 정보 수정]) — 하단 고정 (마감 버튼 체인)
- {개설 직후}: 다음 할 일 3스텝 카드{차수27}

### B4. 요강 탭 (운영자)
(완성도 %카드+채우기 목록) / (요강 미리보기·공유) / ([수정하기]→항목별 편집{3등급})

### B5. 참가자 탭
(부제: 참가 N·출석 N·입금 N) / (세그먼트: 명단|조편성|대기{무제한=숨김}|이전 단계{다단계}) / 명단: (행: 체크인○·이름·전화 마스킹·클럽·입금 뱃지) 행 탭=수정 시트 / [+ 참가자 추가]→[개인|단체] / {다단계 시작 후}: 콜업/제외+사유, [명단 확정]
/ 조편성: {미편성}=빈 화면+[조편성하기]{확정 전=비활성} → 조 카드·맞바꾸기·[다시 편성]·[발송 문구]

### B6. 운영진 탭
(심판 행: 담당·접속 상태) [추가→링크 문구] [재발급] [삭제]

### B7. 스코어 탭
(단계 칩{진입 시 활성 리셋}) / 홀별: (세그먼트 선수별|조별) 선수별=목록(진행)→이름 탭→**입력 전용 페이지**(코스 칩→전/후반 그리드→합계→[완료]) / 조별=조 칩(pan-x)→홀 카드 4인 / 총점만·기간형: (검색)(행: 이름|입력칸|[확인]→✓저장) ✓탭=기록 내역 시트(수정/삭제+사유) {오프라인=전송 대기 배지}

### B8. 리더보드 탭
전광판 동일 2축 필터+행 / 하단 [단계 최종순위 확정]

### B9. 결과 탭
(포디움) (부문 수상) ([인쇄])

### B10. 공통 시트류
접수 마감 확인 / 단계 마감 확인(컷·동점) / 동점 수동 선택 / 정원 초과 선택{무제한=없음} / 기록 내역 / 정정 사유 / 수정 경고(3등급)

## C. 심판 화면 — 토큰 링크
(상단: 안내 문구·본인 확인 셀렉트) / (코스 칩{담당}) / (조 칩) / (홀 카드: N홀·PAR·4인 입력) {오프라인 큐 배지} {done=입력 거부 안내}
