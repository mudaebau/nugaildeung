# 누가일등 — 기능 명세서

## 0. 정보 구조
- **하단 3탭**: 홈 / 내 대회 / MY — 내 대회 카드에 **할 일 뱃지**(대회별 1순위 한 줄, 긴급 코랄/안내 골드 2단, 없으면 미표시)
- **관리공간 7서브탭** (아이콘 언더라인, 균등 폭): 관리홈 / 요강 / 참가자 / 운영진 / 스코어 / 리더보드 / 결과
- 내 대회 1개면 목록 생략하고 관리공간 직행

## 1. 대회 개설 (위저드 — 재편판)
원칙: **경기 구조 필수만 질문. 일반 정보는 개설 후 요강 탭으로.** (CH30 확정)
1. 구조 프리셋 3종: [단판 대회]/[예선+결승]/[예선+본선+결승] — 필드/스크린 질문 폐지(type 내부 파생), 직접 구성 흡수
2. 대회명·주최 (+작명 힌트)
3. 단계 확인: 단계당 요약 카드(아이콘 스펙 타일 2×2)+[상세 바꾸기] 아코디언(한 번에 한 카드) — 방식 세그먼트 **[지정일 라운드|대회기간 라운드]** 단계별 선택(예선 기본=대회기간, 결승·단판=지정일)·코스·조편성·기록·동점. 용어: 사용자 노출 "기간형"→"대회기간 라운드"(내부 kind=period)
4. 일정+정원: **단계 kind 동적 구성**(지정일=날짜/기간=시작~종료/혼합=단계별 블록). 정원=[인원|제한 없음]
5. 완료: [신청 링크 복사] 최우선 + 나중에 입력 목록(심판 등록 포함)
- 한계(기록): 동점 규칙은 대회 전체 단위 — 단계별 규칙은 v0.9 백로그
- 기본값 자동 적용: 참여대상=누구나, 공개, 정보항목=이름·전화(필수)+성별·나이·소속 ON
- 총점만 단계는 동점 선택지에서 홀 카운트백 제외(대체: 최종 코스 총점/연장/연장자/별도선정) + 이유 안내

## 2. 요강 (참가자 화면 = 카드뉴스)
포스터 히어로(상태 뱃지·대회명·일정) → 핵심 4카드(일정/결승·장소/참가비/모집) → 골드 상금 카드(미입력 시 숨김) → 시상 내역 → 진행 방식 도해 → 자격·문의 → 하단 고정 [참가 신청] + ↗공유(링크/이미지 저장). 미입력 항목은 행·카드째 숨김.
**운영자 화면**: 상단 완성도 %카드 + 미입력 [채우기] 목록 + [수정하기].

## 3. 대회 정보 수정 (3등급)
- 자유: 대회명·주최·시상·요강 정보
- 경고(공지 확인창): 일정·장소·정원·참여대상·공개설정 — 정원 축소 시 초과분 자동 대기 전환
- 잠금: 코스 구성·파·단계 구조·컷 — 해당 단계 기록 1건이라도 있으면 불가
- 모든 수정 이력 기록(who/when/what)

## 4. 접수·참가자
- 신청(참가자): 개인(동의 체크 필수, 조건 확인 체크) / 단체=**컬럼 선언형 붙여넣기**(칩으로 줄 형식 선언→선언 순서로 자르기, 실패 줄 보고, 마스킹 미리보기). 서버 검증: 정원·중복 전화·마감 (apply_to_tournament 트랜잭션)
- 접수 상태: 개설 즉시 시작, [접수 마감]/[재개] 수동 제어 — 접수는 단계와 **병행 가능한 독립 축**
- 명단(운영자): 현재 단계 기본 + 이전 단계 조회 탭. 체크인 토글·입금 뱃지(집계 부제 표시). 추가=[한 명씩|여러 명](여러 명=컬럼 선언형: 이름·전화 필수 고정+수집 항목 칩, 클럽도 줄 단위 컬럼), 전화 필수·중복 차단, 정원 초과 시 [대기|정원 확대](무제한이면 생략)
- 대기 승격 / 삭제(점수 있으면 기권 유도) / 기권(WD, 보드 하단)
- 다단계: 진출자 자동 선발 → 콜업/제외(+사유) → **[명단 확정] → 조편성 활성화**
- 무제한 정원: 대기 체계 비활성, 표기 "N명 신청"

## 5. 조편성
- [조편성하기] 버튼으로만 실행 (자동 실행 금지) → **실행 전 확인 시트**: "4인 1조·총 N개 조(참가 M명)·클럽 분산·자투리 처리" 명시 + [3인 조 허용] 토글 → [편성 실행]. 재편성 시 기존 배치 소실 경고
- 두 명 탭 → 맞바꾸기 / [다시 편성] / 추가 인원은 미배정 유지, 삭제는 해당 조만
- 단계 전환 시 group_no 초기화 (새 단계는 빈 조편성부터)
- 조편성표 발송 문구 생성

## 6. 스코어 입력
- **단계 칩**: 진입 시 활성 단계로 리셋(규칙), 완료 단계=조회 전용
- **홀별·선수별**: 목록(진행 N/N·합계) → 이름 탭 → 전용 페이지(코스 칩→전/후반 9홀 그리드+소계→합계·파대비→완료)
- **홀별·조별**: 조 선택(chiprow, touch-action:pan-x) → 홀 단위 4인 입력
- **총점만/기간형**: 행 인라인 입력([확인]→✓저장)+베스트 토스트+[실행 취소]. ✓행 탭=기록 내역 시트(수정/삭제+사유). 라운드형 총점만 재입력=정정 플로우
- **점수 일괄 입력**(총점 모드 전용): 컬럼 선언 [이름·전화 뒷자리·스코어] 붙여넣기 — 매칭=이름+뒷자리(동명이인 무전화=실패 줄), 기간형=새 기록 추가, 라운드형 기존값=실패 줄("개별 수정 이용")
- **목록 정렬**: 조편성 무=가나다순 / 유=조별(조 내 타순·스티키 조 헤더·미배정 하단), 검색 입력=필터 우선
- 기존 값 변경 = 정정 사유 필수 + score_logs
- 오프라인: 실패 시 로컬 큐 → 자동 재전송, "N건 전송 대기" 배지
- 사진 입력: v3 보류 (서버 구조만 보존)

## 7. 리더보드·전광판
- **2축 필터**: 부문[전체|남|여](fields.sex off면 숨김) × 범위[종합|1코스|…](2코스+만). 조합 가능
- 전광판 B안: 소프트블루 그라디언트(#3D71A9→#2E5C8D), 컬럼 순위|선수(클럽 소자)|1C..|스코어|진행|합계 — 폭은 화면 비례(고정 px 금지). 1위=골드 좌바+틴트. 진행="N홀/완료"(홀별) · "n/코스수"(총점)
- 모바일 헤더: 아이콘 3개(전체화면·자동순환·⋯[종료·초기화]) — 첫 화면 순위 7행+
- TV 자동 순환: 부문 축만(전체20s→남10s→여10s). Realtime 끊김=재접속 배지→재구독+전체 재조회
- 리더보드 탭 하단 [단계 최종순위 확정] (관리홈 마감과 동일 로직)

## 8. 단계·컷·종료 (관리홈)
- 여정 바: [접수]→[단계1..N]→[종료], 접수는 뱃지로 병행 표시
- **개설 직후 "다음 할 일" 3스텝 카드**: ✓개설 → 요강 완성(완성도 연동·직행) → 링크 공유. 신청이 쌓이거나 단계 시작 시 자동 소멸
- 하단 버튼 체인: "[단계1] 시작"(조편성 여부 확인창) → "[현 단계] 마감하고 [다음] 시작" → "결과·시상 확정"
- 마감 확인 시트: 순위 확정·컷 선발(남N/여N)·동점 안내·되돌림 불가 경고
- 컷 동점: 규칙으로 자동 해소 시도 → 불가형(연장/별도선정 등)이면 자동 선발 금지, [전원 진출|수동 선택]+로그
- done 후: 모든 입력 차단(심판 토큰 포함), 홈 피드 "지난 대회"로

## 9. 결과·시상
라운드형=포디움+부문상 / **기간형·총점만=단일 리스트형**(1위 골드 좌바+골드 숫자, 코스별 베스트 표)+부문상+**도전왕(최다 플레이)**. 중복 수상 제외 규칙, CSV·인쇄(표 허용 예외)

## 10. 운영진(심판)
운영진 탭에서 [심판 추가](개인/일괄)→문자 토큰 링크(가입 불요, 담당 범위만)→접속 상태 표시. 행 ⋯ 시트=링크 복사/재발급(구 토큰 즉시 무효)/삭제(입력 이력 있으면 비활성화 보존). 신규 대회는 심판 0명 시작(자동 삽입 없음). done 후 입력 차단

## 10b. 내보내기·계정 보안
CSV 4종(참가자·조편성·점수·최종 순위 — BOM, 전화는 마스킹 유지). MY 탭 [보안키 긴급 재발급](무효화→재로그인으로 재발급, 60초 쿨다운)

## 11. 계정·보안·개인정보 (요약 — 상세는 05 문서)
**"시작하기" 단일 화면**(SIGNIN): 회원가입/로그인 분기·인증번호 화면 폐지 — 전화+이름 하나로 신규·재방문 공용, 전화 정규화(표기 무관 동일 계정), 자동 로그인(저장 secret)+재방문 인사("다시 오셨네요"). OTP는 v0.9.
전화번호=계정, operators.secret 소유자 검증, 모든 쓰기 RPC 경유, 비공개 대회 게이트, 동의 체크+?privacy, 전화 마스킹(공개 화면 원본 0)
